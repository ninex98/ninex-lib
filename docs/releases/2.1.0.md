# Ninex Lib 2.1.0

本版本简化生成后的业务开发：Controller 和 Service 都保留清晰的 CRUD 入口，默认通过 `$this->find()`、`$this->create()`、`$this->save()`、`$this->delete()` 调用公共能力。

## 主要变化

- 新增 Laravel EloquentService 和 ThinkPHP TableService，使用各框架原生查询与验证能力；保留原 LibService、公共核心和旧 ThinkPHP 控制器。
- 业务文件直接提供验证规则、scopeQuery、saving、saved、deleted，并附中英文说明。授权、事务和钩子调度由基类统一处理，不需要逐接口编排。
- 字段默认值从验证规则和实际表字段推导，无需重复维护输入、输出、筛选和排序名单；特殊限制仍可按需配置。
- 提供 scopeWhere、scopeWhereLike 实例辅助方法。默认示例只要求普通登录用户，不依赖租户或角色字段。
- Laravel 在认证中间件之后统一解析服务，同时保留直接调用继承的旧 CRUD 方法的兼容性。

## 升级说明

```bash
composer require ninex/lib:^2.1
```

生成器不会覆盖已有业务文件。旧项目可以继续使用原有 Service；新模块使用新的简洁模板。新 Service 对外返回数组或 Page，验证方法返回已验证数组，不应直接替换旧基类而忽略签名差异。

默认生成接口仍按 owner_id 隔离用户记录，创建响应为 HTTP 201，原 HTTP 200 兼容开关保留。已有表结构不会自动修改。保存、删除钩子在提交前执行，关联写入应使用同一数据库连接。

扩展和迁移说明见 [业务 CRUD 开发指南](https://github.com/ninex98/ninex-lib/blob/v2.1.0/docs/GENERATED-CRUD.md)。

## 验证范围

覆盖生成接口、默认字段推导、输入验证、用户隔离、查询过滤、钩子执行顺序、关联写入回滚及旧控制器生命周期兼容；发行归档在无框架、Laravel、ThinkPHP 三个独立宿主中安装验证。
